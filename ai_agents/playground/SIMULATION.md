# TEN Lightcraft

Open `/simulation` on the existing TEN frontend. This is a fictional visual
simulation, not a virtual machine, EEG reader, radio receiver/transmitter,
medical measurement, or claim that thoughts can manifest physical objects.

## Use on a phone

- Select **Resonance** or **Interference** to change the light field.
- Adjust **Focus**, **Calm**, **Frequency**, and **Intensity**. These values
  come from your controls, not from sensors.
- Choose an orb, light crystal, or wave portal. Tap the field or use
  **Manifest a form** to create one. The limit is 20 forms per tab.
- **Pause field** freezes animation and prevents new manifestations.
  **Resume field** continues it. Clear forms or reset all controls as needed.
- **Show system overlay** displays fictional simulation-state information,
  not an actual VM or external system telemetry.

The simulation is independent of TEN's voice worker and security pause.
It does not send its controls to the AI or respond to voice commands.
Its navigation links open the assistant and security controls in a new tab.
Opening the simulation from TEN also uses a new tab so it does not deliberately
disconnect the current call, though mobile browsers may suspend background audio.

State lives in the current browser tab only; reloading resets it. No additional
API, provider key, hardware, or paid model request is needed for the simulation.
Animation respects reduced-motion preferences, pauses in hidden tabs, and caps
drawing resolution and object count for phones. If canvas is unavailable, the
page displays a fallback rather than reporting an active visual display.
